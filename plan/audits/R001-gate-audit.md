## Checked and holding (do not re-audit)

- **Default-deny symbol policy.** `facts_symbols.run`: a product unit's `undefined - own` symbols must be a
  declared dep's export or an explicit per-module `allow`; libc is *not* implicitly allowed, so `dlsym`,
  `syscall`, `mmap`, `open`, … are `undeclared-symbol` even before the deny list. Policy is gate-owned; an
  implementer cannot extend `allow`. `weak`/ifunc/unique defined symbols → `weak-symbol`; defining a libc or
  reserved-prefix name → `symbol-collision`. (R1 is the one gap: `__builtin_` aliases.)
- **ctest result integrity against the implementer.** `g_rep`/`g_nonce` are file-scope statics in `ctest.c`;
  `src` cannot name them (link failure) and is never handed a `ctest_t*`. Report page `memset` per fork;
  pass needs magic+matching random nonce+exit 0+failed==0+asserts>=1; `exit()`/`_exit()`/signal/0-checks/
  nonzero-after-report all fail; no parent fd reaches the child; 10 s SIGKILL. Forgery requires test-author
  cooperation or process-image reading (documented known limit).
- **Preprocessor tricks.** `#include "x.c"` is caught (its text is in the preprocessed scan and its symbols in
  the object); `_Pragma`, `#pragma`, trigraphs, `#line`, `__attribute__((...))` and `[[...]]` (weak/alias/
  ifunc/constructor/section/optnone/no_sanitize/…) are all scanned on the preprocessed text; a user `#line`
  is never believed for system-header classification (`cscan.marker`).
- **Fail-closed inputs.** empty facts/reports/results dir → exit 2; missing gate result → NOT_RUN → verdict
  FAIL; any exception → gate `internal-error` FAIL and pipeline stop; `cli.main` maps non-0/1 handler returns
  and all exceptions to exit 2; a FAIL-by-exception verdict is **not** signed. Strict JSON rejects duplicate
  keys / NaN / Infinity. Result-file status must agree with its findings (`verdict.read_gate_result`).
- **Results/exit cross-checks.** `mutants_verdict.outcome_of_run` requires the binary exit code to agree with
  the parsed pass/fail set and rejects `skip`; a kill counts as `killed-assert` only on a real check-failure
  reason, and every function needs an assert-kill (`crash-only-function`/`no-assert-kill-function` in L3),
  which blocks "tests that only avoid crashing" and TCE-only functions.
- **Tree assembly.** product files read as git blobs (no working tree, attributes, filters, symlinks);
  `ALWAYS_EXCLUDED` strips `.buckconfig*`, `*.bzl`, `tools/`, `toolchains/`, `prelude/`, `gate/`, `.git*`;
  `unsafe_path_reason` blocks `..`/absolute/NUL/empty; symlink and gitlink entries refused; case-fold `BUCK`,
  `PACKAGE`, `BUCK.v2`, `.bzl` caught by `buckfiles.forbidden_name`; BUCK parsed (not executed) with a
  Python-`ast` subset — one `load("@gate//rules:c.bzl", <macros>)`, macro calls with literal kwargs only;
  no `glob()`/`select()`/`read_config()`/concatenation (any non-literal is `bad-argument`/`bad-statement`).
- **Env/determinism.** `grade` clears `os.environ` and gives subprocesses only HOME(empty)/PATH/LANG/TMPDIR;
  `tools/buck2` sha256-pins the client and gets no `BUCK2_BIN`; generated `.buckconfig` copies only
  `[buck2_re_client]`/`[http]` from the gate commit; `--uncached` for decisive grades (B4). git runs with no
  user/system config, `GIT_NO_REPLACE_OBJECTS`, `GIT_GRAFT_FILE=/dev/null`, `--literal-pathspecs`, `-z`.
- **Approvals.** named by sha256 of bytes; signature verified via `allowed_signers` (namespace `c-rigor-gate`);
  exactly 4 keys; `repo_sha` must exist and be an ancestor of head; any stray/unsigned/mis-signed/orphan file
  → `forged-approval`; any approval-shaped file inside the graded tree → `approval-in-repo`; the gate's
  `allowed_signers`/`--approvals` resolve to the running checkout, never product-controlled.
- **Glob / layout matching** (`globs.py`): `**` is a whole segment only, `*` within a segment, everything else
  literal, case-sensitive; protected wins over allowed in the contract. (Include-list B14 is the known gap.)
