# T030: an `--uncached` grade must not re-unpack the 1.6 GB LLVM archive (lane speed, ~2 min per uncached grade)

`--uncached`, backlog B4: the action cache is client-writable), `toolchains/fetch.bzl`, `toolchains/BUCK`,

## Why
T025 measured that the uncached `weak-test` canary spends 113-125 s, twice, on `fetched_tree llvm`: single-threaded
`tar -xJf` of the 1.6 GB release archive, re-run because `--uncached` disables the remote cache for every action. Every
decisive (uncached) grade pays it, and so does `selftest/grade.sh` step 4. Then each mutant wave waits ~35 s for the tree
to reach a worker.

## The idea to measure (or a better one you justify)
The toolchain tree is a pure function of a sha256-pinned download. Trust it from cache **only after verifying it**:
a checked-in manifest (`toolchains/llvm.manifest`: path, mode, size, sha256 of every extracted member) and a small
verify action that hashes the tree and compares. The verify step runs on every grade, uncached (seconds), so a forged
cached tree fails the grade. The 120 s unpack runs only when the cache truly lacks the tree. Same for `sysroot`.
Alternatives to weigh: building `toolchains//...` cached first and then the product with `--no-remote-cache` in the same
daemon; multi-threaded decompression (is the archive multi-block?); a smaller derived archive (would need hosting:
don't publish anything, just report).

## Requirements
1. An `--uncached` grade (and `selftest/grade.sh` step 4) no longer executes `fetched_tree llvm`/`sysroot` when the
   verified tree is available; it executes the verify action instead, uncached. Report wall before and after for step 4
   and for `selftest/canaries.sh --only weak-test --uncached weak-test`.
2. Security: a cached tree that differs from the manifest in any byte, mode, extra or missing file fails the grade (exit
   1, finding in `build` or a new `toolchain` gate), never silently re-fetches. Red tests for each. The manifest is a
   gate file covered by the gate-clean check.
3. The manifest is generated by a documented script from a real unpack, and its regeneration is reproducible.
4. Every other verdict unchanged: `selftest/grade.sh` all steps, the canary pack 0 live misses.
